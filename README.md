# 酒馆小说阅读器

把 SillyTavern 的聊天记录像小说一样随时翻阅。不局限于当前角色、当前聊天——所有角色、所有聊天的内容都可以像读小说一样查阅。

## 功能一览

### 📚 跨角色书架

- 列出酒馆中的**全部角色**，任意切换，不受当前对话限制
- 每个角色下可查看其**全部聊天记录**（历史会话）
- 角色 / 聊天双重搜索，快速定位目标内容
- 角色卡片显示头像与聊天数，一目了然

### 📖 小说式正文阅读

- 聊天记录自动**按消息分章**，形成小说章节结构
- 目录导航：按章跳转、章节分页（可自定义每页章数）
- 说话人标签 + 用户 / 角色配色区分，阅读体验接近小说排版
- Markdown 完整渲染，聊天的排版格式原样呈现
- 正文内检索：在当前聊天中搜索关键词并跳转定位

### 🔖 书签

- 任意章节一键收藏，随时回到想看的段落
- 收藏列表集中管理，按「角色 + 聊天」维度保存，跨会话不丢失

### 📍 阅读进度

- 自动记住每个「角色 + 聊天」的最后阅读位置
- 重新打开时直接回到上次读到的地方
- 也支持「打开时回到书架首页」（会话内首次生效）

### 🗑️ 聊天管理（重命名 / 删除）

- 聊天列表卡片直接**重命名 / 删除**聊天记录（SVG 图标按钮，始终常显）
- 目录页 / 阅读页顶部也可对**当前阅读聊天**执行重命名 / 删除（可在设置中开关）
- 删除前二次确认；删除当前阅读聊天后自动回到该角色的聊天列表
- 重命名 / 删除自动同步**书签与阅读进度**（重命名迁移 key、删除清理数据）
- 与酒馆原生界面 / 其它扩展的删除、重命名操作双向同步（监听 ST 事件）

### 🎨 阅读设置

- 多套内置主题：跟随酒馆、暖纸、墨夜、青简、蔷薇、森语、深蓝
- 字号、行距自由调节
- 移动端 / PC 端分别默认合适的字号

### ✂️ 正则过滤（阅读时自动生效）

- 把酒馆的正则应用到小说阅读渲染：隐藏 OOC 指令、替换敏感词等
- 支持**全局正则**（所有聊天生效）与**角色正则**（仅该角色聊天生效）
- 支持从 **API 预设**启用正则，可跨预设累积勾选
- 勾选状态持久化保存

### 🏷️ 自动识别章节标题

- 从章节正文中提取自定义标签（如 `[zj]`）内的文字作为目录标题
- 可剥离「第一章：」等章号前缀、过滤指定文字

### ⭐ 番外标注与番外指令库

> 适用于聊天中暂时脱离主线、进行番外 / 小剧场 airp 指令的场景。默认关闭，需在设置页开启。

- **楼层标注**：在任意聊天楼层的消息操作栏（三点菜单）点击「标注为番外」，该楼层即在阅读器目录中显示为「番外（标题）」，**不计入章节数**（例：第 1 章、第 2 章、番外、第 3 章）
- **配对隐藏**：标注角色楼层会连同其上方用户楼层隐藏；标注用户楼层会连同其下方角色楼层隐藏（隐藏 = 酒馆原生「从信息词中排除」，只影响 AI 上下文，不影响阅读器渲染，可在设置中关闭）
- **目录过滤**：目录页支持「都看 / 只看主线 / 只看番外」三档切换
- **番外指令库**：标注时用户指令自动收录（未分类），可随时打开指令库面板分类管理
  - 无限层级分类树（新建 / 重命名 / 删除 / 拖拽移动）
  - 指令支持命名、归类、拖拽移动、从 txt 批量导入
  - 点击指令一键填入输入框，继续你的 airp
  - 开启入口：输入框发送按钮旁的「指令库」图标，或设置页开启番外功能后显示

### 🗂️ 文件夹过滤（需搭配 CFM 插件）

- 同时安装了「AAAA-ST-Folder-Manager-V2（CFM）」时，自动启用文件夹过滤
- 角色卡：按 CFM 文件夹树过滤书架角色
- 预设正则：按 CFM 文件夹树过滤预设
- 折叠树形面板：全部 / 未归类 / 层级文件夹，支持一键展开收起
- 未安装 CFM 时功能自动隐藏，不影响使用

### 🖥️ 界面与体验

- 全屏阅读界面，顶部搜索 + 底部操作栏
- 阅读器图标可自定义（支持自动检测美化主题图标）
- 移动端适配：弹窗高度、按钮尺寸、面板宽度自动调整
- 大聊天文件分批渲染，翻章流畅不卡顿

## 安装

1. 将本目录复制到 SillyTavern 的 `public/scripts/extensions/third-party/` 下
2. 刷新页面，在扩展工具栏中找到「酒馆小说阅读器」入口
3. 点击打开，开始翻阅你的小说吧

## 兼容性

- 仅需 SillyTavern 本体即可运行全部核心功能
- 文件夹过滤为可选增强：需同时安装 [AAAA-ST-Folder-Manager-V2](https://github.com/)（CFM）
